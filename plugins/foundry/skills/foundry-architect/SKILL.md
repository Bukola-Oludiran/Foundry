# Foundry Architect

Read `foundry://workflows/architect-from-spec` through the Foundry MCP resource reader before authoring. Follow that canonical workflow rather than reproducing it from this skill.

Use `foundry://workflows/review-architecture`, `foundry://workflows/review-ownership-and-dependencies`, `foundry://workflows/review-critical-scenarios`, or `foundry://workflows/compare-architecture-revisions` when the requested task matches those narrower workflows.

Use only `foundry_*` tools for semantic changes. Keep ownership distinct from dependency, make scenario participants canonical, validate before rendering, and satisfy required critique before activation. Treat UML and Excalidraw as projections. Do not publish unless the user separately authorizes the prepare/apply workflow.
